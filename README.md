# Fair Quote Hub

Дипломный проект на тему **«Хранилище рыночных данных и единые цены»**.

## О проекте

Сервис для сбора, хранения и обработки рыночных данных об акциях, облигациях, валютных парах и других финансовых инструментах. Цель — объединить данные из разных источников и рассчитывать единую котировку по выбранной методике «справедливой цены».

## Планируемые возможности

- Загрузка данных из внешних источников: Московская биржа, Cbonds, НРД, RUDATA.
- Приведение данных к единому формату и проверка их качества.
- Хранение исходных и обработанных данных по слоям.
- Расчёт единой цены финансового инструмента.
- Предоставление котировок и данных для аналитики.

## Архитектурный подход

В основе планируется Data Lakehouse для исторических данных и отдельное хранилище для оперативного доступа к актуальным котировкам.

Поток данных: **источники → загрузка → обработка и хранение → расчёт цены → аналитика**.

Окончательный стек, состав источников и методика расчёта цены уточняются в ходе проектирования.

## Текущий статус

Проект находится на этапе проектирования: подготовлена предварительная архитектура и создан репозиторий. Инструкции по запуску и описание компонентов будут добавляться по мере реализации.
